# bungkus-mcc — Design Language ("Daun Pisang")

Status: proposal, revision 2. This is the shared visual language for bungkus
products; bungkus-mcc is the first to use it in full, bungkus-cli adopts it
later (§2.4). Every mockup in this file was generated by a script and
width-checked cell by cell (`scratchpad/mock/gen.py` + `check.py` from the
review round; they move into `internal/tui/testdata/` when code starts).

## 1. The image

Nasi lemak, bungkus-style: coconut rice on a square of banana leaf, folded
into a pyramid, wrapped again in newspaper, rubber band around it. Open it:
sambal (red, oily), half an egg (yolk), cucumber, fried ikan bilis and
peanuts, the leaf's green underneath.

| Element             | In the UI                                                |
|---------------------|----------------------------------------------------------|
| Daun pisang (leaf)  | Focus, running, healthy. Green.                          |
| Sambal              | Failure. Red-orange, used sparingly.                     |
| Kuning telur (yolk) | Attention: the agent is waiting for you. Amber.          |
| Nasi (rice)         | Primary text: the terminal's own foreground.             |
| Surat khabar        | Secondary text, chrome. Newspaper gray.                  |
| Minyak sambal       | Brand accent (title, selection). The oil stain on paper. |
| Getah (rubber band) | The status/mode bar that holds the packet together.      |
| Bungkus             | Done. A finished session is "wrapped".                   |

Theme name: **Daun Pisang** (`daun-pisang-dark`, default) and
**Daun Pisang Pagi** (`daun-pisang-light`).

## 2. Palette

Rules that apply to every bungkus product:

1. **Never paint a background.** Not the screen, not cards, not surfaces
   (decided in review: the light card surface dropped `accent` to 4.17:1).
   The terminal's background is the background. Selection uses reverse
   video, which by definition contrasts.
2. **`fg` is the terminal's default foreground.** We do not set it. Contrast
   for `fg` is the user's theme's responsibility, which is the only way to
   be correct on all of Nord, One Dark, Catppuccin, Gruvbox, Solarized.
3. **Every state is glyph + word + colour.** Colour is never the only carrier.
4. Colours are declared once as truecolor hex plus an explicit 256 and 16
   index. The explicit indices start from `x/ansi.Convert256/Convert16`
   output and are overridden only where the converter makes two roles
   collide (marked ★). A test asserts `ok/warn/err/accent` are pairwise
   distinct at 256 and at 16 in both themes, and `fg-muted ≠ info`.

WCAG formula: (L1 + 0.05)/(L2 + 0.05), sRGB relative luminance. AA text
4.5:1, AA large/bold and non-text 3:1. Because we don't paint backgrounds,
ratios are given against the five most common dark terminal backgrounds.

| `warn`       | Kuning       | `#e8c547` | 185 | 11 | needs you, INTERACT mode word             | 11.93 | 7.44 | 8.34 | 9.77 | 8.78 |

Notes. `fg-muted` was re-picked from Lackluster's `#708090` (3.5:1 on Nord)
to `#8a99a8` so it passes AA on all five; the converter maps it to 103/blue,
so it is declared 245/7 (gray/normal white) to read as "muted", and to stay
distinct from `info` (68/12). `accent` auto-converts to 16-colour 9, the same
as `err`, so it is declared 3 (most 16-colour palettes' "yellow" is an
ochre — close to sambal oil). `border` at 16 is declared 8 (bright black)
because 0 vanishes on a black background. `info` is 3.82 on Nord — below AA;
it never carries state or text the user must read (ids, link decoration,
the low-urgency "your turn" glyph, whose word is in `fg`). Sambal moved from
`#ff5c47` (4.09 on Nord) to `#ff7361`.

Inverse badges (`#080808` text on the token as background — used only for
the mode word in the getah bar and the `!`/`✗` gutter): on warn 11.93, ok
7.93, err 7.51, accent 10.83. Never `fg` on `err` (fails).

At 16 colours the converter maps `accent`, `warn` and `err` all to 1 (red)

Theme selection: `theme: "auto" | "dark" | "light"` in config (auto uses
Bubble Tea's `BackgroundColorMsg`; when the terminal does not answer,
dark). No runtime toggle key (cut in review; edit the config).

### 2.3 Fallback ladder

Detection (`COLORTERM`, `TERM`, `NO_COLOR`, `CLICOLOR_FORCE`, tmux) is Bubble
Tea v2 + colorprofile's job. We hand it the declared colour for the active
profile (`tea.ColorProfileMsg`), so no downsampling surprises. At 16 colours
and under `NO_COLOR` the UI must be fully usable: glyph + word per state,
focus by border weight + `▸`, selection by reverse video.

### 2.4 Relationship to the Lackluster palette (bungkus-cli)

Decision: **evolve — keep the neutrals' roles, replace the values that fail.**

| Dim, Dark, Gray1 | `#555555`, `#2a2a2a`, `#080808` | kept; decorative only; Gray1 is a reference bg, never painted |
| Orange     | `#ffaa88` | kept → `accent`                                                     |
| Green      | `#789978` | → `ok` `#7fb069` (Lackluster's collapses to gray 244 at 256 colours) |
| Yellow     | `#abab77` | → `warn` `#e8c547`                                                  |

bungkus-cli adopts this by replacing `internal/tui/styles.go` with a copy of

## 3. Typography and glyphs

A TUI does not choose the font. We choose code points.

- **Recommended fonts** (README, not enforced): any Nerd Font monospace, or
  the terminal default with a symbol fallback (kitty `symbol_map`, Ghostty's
  bundled Nerd Font symbols).
- **Three glyph sets**, `icons: "nerd" | "unicode" | "ascii"` (config or
  `--icons`). Default `unicode`: the font cannot be detected, so the default
  uses only glyphs every monospace font has. `ascii` is auto-selected when
  the locale is not UTF-8 or `TERM` is `linux`/`dumb`. All glyphs are 1 cell.
- **Width risk (real, Japan-based team):** `●○■◆▶` and the box-drawing set
  are East Asian *Ambiguous* width. Terminals set to "ambiguous = wide"
  (common with CJK locales in iTerm2/kitty) render them 2 cells while
  lipgloss/x/vt count 1, and columns shift. Mitigation: every state and
  marker glyph below is *Narrow* (checked with `unicodedata.east_asian_width`);
  borders remain ambiguous, as do the `·` separator (U+00B7) and the
  logomark glyphs `▲ ╱ ▁ ‖` (every terminal we target draws them 1 cell in
  practice; `--icons ascii` switches borders to `+-|`, `·` to `|` and the
  logomark to its ascii form). A recorded
  stream test with CJK, emoji and `⏺ ⎿` (Claude's own output) asserts the
  emulator's column positions match wcwidth — see CODING_RULES.md.

| Meaning       | nerd (U+)      | unicode | ascii | width class |
|---------------|----------------|---------|-------|-------------|
| running       | spinner        | braille `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` | `\|/-\` | N |
| your turn     | U+F0E7 (bolt)  | `»`     | `~`   | N |
| needs you     | U+F071 (warn)  | `!`     | `!`   | Na |
| failed        | U+F00D (times) | `✗`     | `x`   | N |
| wrapped       | U+F00C (check) | `✓`     | `+`   | N |
| stopped       | U+F04D (stop)  | `▪`     | `#`   | N |
| subagent      | U+F0DA (caret) | `◦`     | `-`   | N |
| focus marker  | U+F0DA         | `▸`     | `>`   | N |
| INTERACT      | U+F11C (kbd)   | `►`     | `>`   | N |
| limit bar     | —              | `▮▯`    | `#-`  | N |
| agent badge   | `C` / `X` letter in `accent`, all sets |

Nerd Font code points are private-use; patched "Mono" variants render them
1 cell, "Propo" variants may not — another reason `nerd` is opt-in. Glyphs
are emitted only through `theme.Icon(name)`; a table test asserts widths.

- **Borders** (three weights, three ascii forms):

| Pane state | unicode                      | ascii            |
|------------|------------------------------|------------------|
| inactive   | `┌─┐ │ └─┘` light            | corners `+`, `-` `\|` |
| focused    | `┏━┓ ┃ ┗━┛` heavy, plus `▸` on the selected row | corners `#`, `=` `\|` |
| INTERACT   | `╔═╗ ║ ╚═╝` double           | corners `*`, `=` `*` |

- No italics, no underline for meaning. Bold only for emphasis.
- OSC 8 hyperlinks: on the workspace path in the header only, text identical without it.

## 4. Layout

Three columns. Widths are **outer** (including the border), inner = outer − 2.

| Pane     | Outer width           | Inner |
|----------|-----------------------|-------|
| projects | 22                    | 20    |
| sessions | 38 (fixed)            | 36    |
| output   | remainder, ≥ 40       | ≥ 38  |

Rows: line 1 header, lines 2…H−1 panes (outer height H−2), line H getah bar.

Breakpoints: **≥ 100 columns → three panes**; **< 100 → single-pane stack**
(one pane at a time, breadcrumb in the header, `h`/`l` move through the
stack). Minimum size **80×24**; below that a single centred line:
`bungkus-mcc needs at least 80×24 (now 72×20)`. No other tiers.

## 5. Components (the reusable part)

Future bungkus products **must keep**: the palette and its rules (§2), the
three border weights, the glyph table and its ascii twins, the getah bar
anatomy, the state vocabulary (§5.3), the voice (§5.6), the logomark.
They **may vary**: layout, which panes exist, keys beyond the global set,
whether there is a header line.

### 5.1 Getah bar (status bar, always the last line)

`␣MODE␣␣<keys for the focused pane, · separated>` … right-aligned `<global figures>`.

- Mode word first, reverse video: `NORMAL` in `fg-muted`, `INTERACT` in
  `warn`, `FILTER` in `info`.
- Keys are for the **focused pane only**, generated from the keymap.
- Truncation when narrow, from the right: global figures go first, then the
  key hints one by one from the end. Never dropped: the mode word, `? help`,
  and in INTERACT the exit chord.
- Transient messages (errors, "copied") replace the key hints for 5 s.

### 5.2 Card anatomy (sessions pane, inner width 36)

```
┃! C #a3f1 write proposal            12m   gutter · state glyph · agent badge · #id · title · right: elapsed or state word
┃  needs you · permission: Bash            line 2: state word · detail (tool / prompt kind / exit line)
┃  499k tok · $1.42 · ctx 37%              line 3: compact usage (`-` when unknown)
┃  ◦ research hooks             ⠹ 3m       one line per subagent (flat list): glyph · description · state glyph · time
```

- Gutter column: `┃` in `warn` for needs-you, `err` for failed, space otherwise.
- Title: the first prompt line, sanitised, truncated to fit; fallback when
  there was no prompt: `claude session` / `codex session`.
- `#id`: first 4 hex chars of the agent's own session id, in `info`.
- Cards never collapse; when the pane is short, it scrolls (the selected
  card is kept in view). **The selected card is expanded (§6.3) only while
  the sessions pane is focused**; when focus is elsewhere every card is the
  compact 3-line form, so the pane reads the same whichever card is selected.
- Truncation: every line is cut to the inner width with a trailing `…`.
  Lines with a right-aligned field (elapsed, state word, subagent time) keep
  the right field and truncate the left text. The usage `limits` line drops
  its `↻` reset times first, then truncates; the `cost` line drops its
  parenthetical first. The card mocks below are inner width 36; the
  expanded mock in §6.3 has `▸` in column 1, leaving 35.

### 5.3 State vocabulary (decided)

| State     | Glyph (unicode/ascii) | Word      | Colour   | Meaning / trigger                                                      |
|-----------|-----------------------|-----------|----------|------------------------------------------------------------------------|
| running   | spinner / `\|/-\`     | working   | ok       | main turn active **or any subagent running**; any Pre/PostToolUse or SubagentStart sets it |
| your turn | `»` / `~`             | your turn | info glyph, `fg` word | Stop received and no running children; not muted (it is a prompt to act) |
| needs you | `!` / `!`             | needs you | warn + gutter + bold title | permission_prompt / agent_needs_input / elicitation_dialog (Claude), PermissionRequest (Codex). `idle_prompt` is ignored |
| failed    | `✗` / `x`             | failed    | err + gutter | process exit ≠ 0                                                    |
| wrapped   | `✓` / `+`             | wrapped   | ok glyph, `fg-muted` card | process exit 0                                              |
| stopped   | `▪` / `#`             | stopped   | fg-muted | stopped by the user (`x`)                                              |

Subagents use the same glyphs at one indent with `◦`; their status comes
from `background_tasks` on Stop/SubagentStop (authoritative), else from
SubagentStart/Stop.

Sidebar badge = worst state among the project's sessions, precedence
**failed > needs you > running > your turn**, shown as `<glyph> <count>`.

### 5.4 Badge

`<glyph> <count>` or `<letter>`; one cell glyph, one space, digits. Agent
badges are the letters `C` (Claude Code) and `X` (Codex) in `accent`.

### 5.5 Dialogs

Centred, double border (they take input like INTERACT), title in the top
border, one blank line of padding, hint line last, right-aligned. `esc`
always cancels; destructive confirms take `y`, anything else is "no".

```

║                                            ║   ║                                            ║
║  agent   ▸ claude    codex                 ║   ║  2 sessions are still working. They will   ║
║  prompt  ┃                              ┃  ║   ║  be stopped; resume them later with r.     ║
║                                            ║   ║                                            ║
║  enter start · tab agent · esc cancel      ║   ║                           y quit · n stay  ║
```

## 6. Usage figures (tokens, cost, context, plan limits)

Sources and honesty about them are in ARCHITECTURE.md §6. On screen:

### 6.1 Global: plan limits in the getah bar

`5h ▮▮▮▯▯ 42% · 7d ▮▯▯▯▯ 18%` — the most recent `rate_limits` received from
any Claude session (limits are per account, not per session). Bars are 5
cells (20 % each); `warn` colour from 80 %, `err` from 95 %. Omitted
entirely when no session has reported limits (API-key users, Codex-only
users): nothing is shown rather than `-`, because the bar is global. When a
window's `resets_at` has passed and no fresher report has arrived, the
figures are shown dimmed (`fg-muted`) as stale until the next report.

### 6.2 Per card, compact (line 3)

`499k tok · $1.42 · ctx 37%` — tokens (input incl. cache + output, k/M
abbreviated), cost as the agent reports it, context fill %. The unknown
marker is ASCII `-`: a Codex card reads `- tok · - · ctx -` until a source
exists; a Claude card reads `-` for `ctx` before the first reply
(`used_percentage`/`current_usage` are null then) and again once wrapped
(the last report is not a live context). `ctx` turns `warn` at 80 % and
`err` at 90 % — ASSUMPTION that 90 % is Claude's auto-compact point; the
thresholds are constants to adjust in M5. Token semantics as reported by
Claude's status line: `total_input_tokens` **includes cache** reads/writes
and may be per-request rather than cumulative (ARCHITECTURE.md §6.2); the
mock numbers follow that reading (in 486k = 65k fresh + 402k cache read +
19k cache write).

## 8. Keybindings

Vim motions and arrow keys, everywhere. One file (`internal/tui/keymap.go`,
`bubbles/key.Binding`), grouped per pane and per mode; the help overlay and
getah bar are generated from it. Uniqueness is tested **per pane/mode**, so
`n` can mean "new session" in the sessions pane and nothing elsewhere.

| `j` `k` · `↓` `↑`                                 | move / scroll                           |
| `gg` `G` · `home` `end`                           | first / last                            |

### 8.5 INTERACT

Every key, paste and (if the agent enabled it) mouse event goes to the
agent, including `q`, `?`, `ctrl-c`, `esc`. Exceptions:

| Keys                 | Action                                                            |
|----------------------|-------------------------------------------------------------------|
| `ctrl-\` (default)   | leave INTERACT. Configurable: `interactExit` in config, any single chord (suggested alternate: `ctrl-^`) |
| `ctrl-z`             | swallowed (a suspended agent cannot be resumed from inside a pane)  |
| mouse click on another pane | leaves INTERACT and focuses that pane                       |

Why `ctrl-\` by default: a plain C0 byte (0x1C) that arrives even without
the kitty protocol and through tmux without `extended-keys`; not a vim
motion; not bound by Claude Code or Codex (Claude Code documents `ctrl-\`
as reserved, which is why they don't use it). Known clashes, hence the
config key: **vim-tmux-navigator** binds `C-\` (and `C-h/j/k/l`) in tmux;
**VS Code / Cursor** may bind `ctrl+\`; on **JIS** keyboards `\` is the `¥`
key (kitty/iTerm2/Terminal.app send 0x1C for ctrl-¥ — verify in M3); on
**German** layouts `\` needs AltGr. Suggested alternate: `ctrl-^` (`ctrl-]` is taken by `!`'s twin).
`esc` is never the exit: agents use it constantly. To send a literal exit
chord to the agent: not supported in stage 1 (no agent needs it).

zellij note: zellij's default modes eat `ctrl-g/p/n/t/o/s/h/q` before any
app sees them (`ctrl-g` toggles *lock mode*, which then passes everything
through); `ctrl-\` is not among them.

### 8.6 Mouse

Click focuses a pane / selects a row (and exits INTERACT if the click is
outside the output pane); wheel scrolls; click inside the output pane in
NORMAL does **not** enter INTERACT. Text selection: with mouse reporting on,
terminals need a modifier to select (kitty/Ghostty/iTerm2 `shift`-drag,
WezTerm/Alacritty `shift`, Terminal.app `option`-drag) — shown in the help
overlay; `--no-mouse` / `mouse: false` turns reporting off entirely.

## 9. Notifications

Setting `notify: "bell" | "desktop" | "off"`, **default `bell`**.

- On the transitions **→ needs you** and **→ failed**: `bell` sends BEL
  (terminals map it to a sound, a badge or a tab highlight); `desktop`
  additionally sends a desktop notification via OSC 9 (iTerm2, WezTerm,
  Ghostty, VS Code), OSC 99 (kitty) or OSC 777 (urxvt-style, foot),
  chosen by `TERM_PROGRAM`/`TERM`; inside tmux/zellij OSC 9 is passed
  through only where the multiplexer allows it — degrade to `bell`.
- Terminal title (OSC 2) always reflects the tally: `bungkus-mcc · 1 needs
  you` / `bungkus-mcc · 2 working` / `bungkus-mcc`. The previous title is
  saved and restored with XTWINOPS push/pop (`CSI 22;0t` on start,
  `CSI 23;0t` on exit); terminals without it simply keep our last title.
- The header tally and getah-bar tally are visible in every mode.
